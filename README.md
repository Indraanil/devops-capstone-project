# DevOps Capstone Project

[![Build Status](https://github.com/Indraanil/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/Indraanil/devops-capstone-project/actions)

## Project Overview
This repository contains the microservice application for the IBM DevOps and Software Engineering Capstone Project. It provides a RESTful Account Service with full CRUD operations, automated unit tests, continuous integration, containerization with Docker, and Kubernetes deployment.

## Features
- RESTful Account API (Create, Read, Update, Delete, List)
- Flake8 linting and Pylint configuration
- Test-driven development with Nose tests and code coverage
- Security headers using Flask-Talisman and CORS support using Flask-CORS
- Continuous Integration pipeline via GitHub Actions
- Containerization with Dockerfile
- Automated CD deployment via Tekton Pipeline
